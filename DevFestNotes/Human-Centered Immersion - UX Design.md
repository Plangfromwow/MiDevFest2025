Must do's in design for immersive environments 
- Affordances 
	- Guiding users without overwhelming them 
		- Handles switches doorknobs are ex.
	- How is it used? 
		- Prioritizing features when designing interactions 
		- use design qualities that guide user behavior (color, shape, material, contrast, and placement)
	- user needs to discover for themselves but you shouldn't overwhelm / confuse 
- Interaction
	- Make actions feel natural, responsive, and easy to understand 
	- How? 
		- Using real hands on actions instead of confusing abstract gestures 
	- Interacting via pushing, pinching, grabbing and pulling - Make them feel real and easy to use 
- User Comfort 
	- Placing UI in easy to reach, in a comfortable distance, and in a clear view 
	- how? 
		- Don't place elements close to users 
		- don't place objects too low or too high probably 
		- place ui in the middle third of the users fov so it's easy to see without straining 
- Environmental Graphic Design Principals? 
	- How can the env guide users naturally? 
		- Apply signage, landmarks, color coding, and spatial cues to guide the users and reduce confusion 
	- using colored path to lead users clear signs for key areas, or distinct landmarks to orient them 
	- This should also apply to normal UI's as well I feel 
- Should focus on delivering ready product for them, do not give them too many steps if they are not needed / are not really customized often
